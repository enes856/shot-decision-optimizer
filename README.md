# NBA Shot Decision Optimizer

## 1. Project Description
This project is part of the "Project Big Data" module of the University of Applied Sciences Munich. It serves as a comprehensive tool to analyze and optimize NBA shot selection strategies using Machine Learning. By leveraging play-by-play data, the system predicts the probability of shot success based on critical features such as shot distance, defender proximity, shot clock remaining, and player statistics.

The core of the project involves a data processing pipeline, predictive modeling (using Logistic Regression and XGBoost), and an interactive dashboard for visualizing insights.

## 2. Prerequisites
To run this project successfully, the following environment is required:

* **Operating System:** Windows, macOS, or Linux
* **Python Version:** Python 3.10 or higher
* **Package Manager:** **uv**
    * This project exclusively uses `uv` for fast and reliable dependency management.
    * **Installation:** If not installed, please follow the official guide: [https://docs.astral.sh/uv/](https://docs.astral.sh/uv/)

## 4. Installation & Setup

This project uses `uv` to handle the virtual environment automatically.

1. Open your terminal in the root directory (`shot-decision-optimizer`).
2. Run the sync command:
```bash
uv sync
```


*Note: This command automatically creates a virtual environment (`.venv`) and installs all necessary dependencies defined in `uv.lock`.

## 5. Data Preparation & Execution (Step-by-Step)

Follow this workflow to prepare the data and launch the application.

### Step 1: Acquire Raw Data

This project uses three types of data: **raw**, **processed**, and **prediction** data.

**Important:**  
All required data files are available in the shared Google Drive under the `data/` folder.  
The Drive contains:
- `raw/` — original play‑by‑play data
- `processed/` — parquet files generated by the main notebook
- `predict/` — files used for the prediction pipeline

#### Option A (Recommended): Download everything from Google Drive
Download the full `data/` directory from the Drive and place it directly into the project:

**Link:** [Google Drive - NBA Data](https://drive.google.com/drive/folders/1T1-h9LpgQnZLZuGUTbpXX_wjiCo99mcY?usp=sharing)  
**Action:** After downloading, ensure your local structure is:

```
data/
  raw/
  processed/
  predict/
```

This is the fastest way to get started.

#### Option B: Fetch *raw* data via API
If you prefer to fetch fresh data, you can use the notebook:
`notebooks/load_data_from_api.ipynb`.

> Note: This step only generates the **raw** data and is very slow due to API rate limits.

The **processed** and **predict** files will still be produced later by the main notebook, even if they already exist from the Drive.

### Step 2: Process Data

Whether you downloaded the data from Drive or fetched it via the API, you should still run the processing step.  
The main notebook will (re)generate everything needed — including all files inside `data/processed/` and `data/predict/`.  
(These files are also included in Drive only as a backup.)

1. Run the main processing notebook:
```bash
uv run jupyter notebook notebooks/shot_decision_optimizer.ipynb
```


2. In the opened Jupyter interface, execute all cells (**Run All**).
* *Result:* This will generate the required `.parquet` files inside the `data/processed/` folder. It will also generate the files used for predictions in `data/predict/`.

> **Tip:** You can execute any other notebook in this project (e.g., `xg_boost_modeling.ipynb`) using the same command structure. Simply replace the filename:
> ```bash
> uv run jupyter notebook notebooks/<notebook_name>.ipynb
> ```


### Step 3: Launch Dashboard

After the data is processed:

1. Run the Streamlit dashboard using `uv run`:
```bash
uv run streamlit run dashboard/app.py
```

2. The dashboard will launch in your default browser at `http://localhost:8501`.  
   > ⚠️ If port 8501 is unavailable, Streamlit will use the next free port (check the terminal for the URL).

### Logging In

- There are 30 accounts for each NBA Team. 
- Use your **team account credentials** to log in.  
- Each team account follows this format:  
  - **Username:** `team_name` (e.g., `los_angeles_lakers`, `chicago_bulls`)  
  - **Password:** `team_name_123` (e.g., `los_angeles_lakers_123`, `chicago_bulls_123`)  
- A **CAPTCHA** needs to be completed to verify that you are human.

---

### Using the Dashboard

- **Filter games** by player, team, or date to focus your analysis.  
- **Click on a shot** (*STRG + Left Click*) to watch the exact game footage.  
  > ⚠️ Important: NBA videos only open in a **new tab**. Normal clicks may be blocked, and you might need to reload the page.  
- Each game card provides **detailed analytics**, including:
  - High-risk shot analysis  
  - Player and team performance metrics

## 6. Known Limitations & Notes

* **Data Source:** The analysis relies on the 2024-25 NBA season data.
* **Execution Order:** The dashboard requires the `.parquet` files generated in Step 2. It will not start correctly if the data processing step is skipped.
* **Model Files:** Pre-trained models are located in the `models/` directory.
* **Data Folder in Drive:** All data folders (`raw`, `processed`, `predict`) are available in the shared Drive. The notebook can always recreate `processed` and `predict`, but they are included for convenience.
